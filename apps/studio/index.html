PPTX Studio — open, inspect, hand it back

Drop a .pptx and read its internals: every part, every content type, the relationship graph, and a census of the features it uses keyed to the phase of the plan that renders each one — then save it back out and open the result in real PowerPoint. Nothing is uploaded. The file is read, checked and written in a Web Worker in this tab, by the same code pptx-studio inspect and pptx-studio roundtrip run.

Slides are drawn too — geometry, fills, gradients, patterns, strokes, effects and nested rotated groups, with a debug overlay on any shape you click, and text laid out and drawn as real <text>: the cascade, line breaking, autofit, bullets, anchoring and the baseline PowerPoint itself puts the glyphs on. See also the 187 preset shapes, with their adjust handles live.
