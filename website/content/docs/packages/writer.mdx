## What it is

`openPackage` opens a deck twice - once to edit and once as an untouched baseline. `exportPackage` writes the archive with only the rewritten parts serialised afresh, checks that every other entry is byte-identical to the baseline, runs the 31 rules, and returns bytes only if both pass. `comparePackages` is the round-trip comparator the CI badge is made of, and `bisectPackages` narrows a breaking change to the smallest edit that reproduces it.

## Key concepts

### Why the writer may not understand the document

It streams parts it never parsed. That is the property that lets charts, SmartArt, macros and OLE objects survive a save from code that cannot draw them.

### The baseline is not optional in practice

Without it three rules, the media sweep and the preservation check quietly skip themselves. `openPackage` gives you both stores from one set of bytes.

### Media collection is timid on purpose

Only media orphaned by this session's edits is swept, and only when the reachability walk was complete; a part something unparsed might still point at is kept.

### Round trip is not a byte comparison

XML parts are compared canonically, relationships as graphs with opaque ids, binaries by digest. Entry order and deflate level differ legitimately between two archives holding one document.
