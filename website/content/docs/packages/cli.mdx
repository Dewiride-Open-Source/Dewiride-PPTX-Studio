## What it is

`pptx-studio render` draws every slide to SVG with no browser and no LibreOffice, measuring text from the font tables on the machine. `inspect`, `validate`, `roundtrip` and `bisect` are the other packages' functions with a file argument and an exit code. `renderDeck` is the same renderer from a program.

This is the one package that imports Node. Everything it knows about `.pptx` lives in the browser packages beneath it.

## Key concepts

### Everything it knows lives somewhere else

The CLI adds files, arguments and exit codes to the browser packages. A question answered on the command line and one answered in a tab cannot drift, because they are the same function.

### `render` measures with font tables

With no canvas, the CLI indexes the machine's font files, reads advances and kerning out of the SFNT tables, and measures from those. Which face drew which run is reported, never hidden.

### A machine with no fonts substitutes everything

A container that ships no faces draws every typeface in a fallback and the report says so - that is where you would find out, rather than in a wrong-looking picture.

### No PNG, no shaping

Output is SVG. Complex scripts are measured without a shaper, so Arabic and Devanagari measure wide; the face box follows the machine that renders.
