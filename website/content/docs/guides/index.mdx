title: Guides
description: 'Task-shaped walkthroughs, each with the code, the errors it can raise, and the demo to try it on.'
---

- [Render a deck to SVG in the browser](/docs/guides/render-svg-in-the-browser) - Read a .pptx from a file input and draw every slide as an SVG string, entirely in the tab.
- [Show a live slide with render-dom](/docs/guides/live-slide-with-render-dom) - Mount a slide as real SVG elements, zoom it, watch the device pixel ratio, and build a thumbnail strip.
- [Read what is inside a deck in a Web Worker](/docs/guides/read-a-deck-in-a-worker) - Run the census off the main thread, show progress, and hand back plain JSON.
- [Edit a shape and save a file PowerPoint opens](/docs/guides/edit-a-shape-and-save) - Move, colour or retype a shape as XML edits with exact inverses, then export with the firewall on.
- [Validate before you ship](/docs/guides/validate-before-you-ship) - Run the 31 rules on a file somebody sent you, or on an export, and read what they say.
- [Server-side thumbnails with the CLI](/docs/guides/server-thumbnails-with-the-cli) - Render every slide to SVG in Node, with no LibreOffice and no headless browser.
- [Understand the inheritance chain](/docs/guides/understand-the-inheritance-chain) - Ask where a shape's position, fill or text size came from, and get the sheet that said so.
- [Geometry presets and adjust handles](/docs/guides/geometry-presets-and-handles) - Resolve a preset or custom geometry to SVG paths at a size, and turn a handle drag into an adjust value.
- [Colour, gradients and patterns](/docs/guides/colour-gradients-and-patterns) - Resolve a DrawingML colour through its theme, build the SVG for a gradient or a pattern, and stroke a dash correctly.
- [Text measurement and autofit](/docs/guides/text-measurement-and-autofit) - Measure runs, break lines, walk the autofit ladder, number bullets and find out which face will draw.
