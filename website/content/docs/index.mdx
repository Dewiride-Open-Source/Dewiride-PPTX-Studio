## What you get

Every `@pptx-studio/*` package is ESM, ships its own TypeScript types, and runs in a browser tab or
a Web Worker. One of them, the CLI, runs the same renderer in Node.

```sh
npm install @pptx-studio/opc @pptx-studio/model @pptx-studio/render-svg
```
