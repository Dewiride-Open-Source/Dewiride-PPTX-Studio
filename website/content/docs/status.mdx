The plan is thirteen phases. This page is generated from the same file as the repository's plan
table, and a sub-phase only turns green here once its architecture decision record exists. There
are no dates: the plan names phases, not quarters.

## What is drawn today

Shapes, groups, pictures, fills, gradients, patterns, strokes, effects, and text with bullets,
fields, autofit and vertical runs. A hundred-slide deck at any zoom, entirely in the tab.

## Preserved, not drawn

Tables, charts, SmartArt, OLE objects, ink, 3-D models, video, audio, animations and macros are
carried through an export byte for byte and shown as frames. Tables and SmartArt are phase 4;
charts are phases 9 and 10.

## How to read this

This site is rebuilt after a release and installs the packages from npm, so it can sit one release
behind the repository. The version pill in the footer says which versions it was built against.
